# Data folder

Raw Compustat/WRDS data are proprietary and should not be uploaded to GitHub.

For the empirical application, place the WRDS extract locally as:

```text
data/raw/df0_WRDS.csv
```

Expected variables include: `gvkey`, `datadate`, `fyear`, `sich`, `at`, `dltt`, `dlc`, `ppent`, and `ib`.
